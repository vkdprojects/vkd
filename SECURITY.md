# Security policy

## Supported versions

Security fixes go into the newest release of vkd. Update to the latest version before reporting.

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately with GitHub's [private vulnerability reporting](https://github.com/vkdprojects/vkd/security/advisories/new) on this repository. Only the maintainers can see the report. Please include:

- what is affected and the version or commit;
- steps to reproduce, or a proof of concept;
- the impact as you understand it.

You get an acknowledgement within 7 days. We credit you in the release notes and the advisory unless you prefer to stay anonymous, and ask that you give us time to ship a fix before you disclose publicly.
